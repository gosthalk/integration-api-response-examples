## Удаление пользователей
### Список ошибок
| Атрибут | Ошибка                                             | Описание                                            |
|---------|:---------------------------------------------------|-----------------------------------------------------|
| login   | Value is required                                  | Значение обязательно                               |
| login   | Value must be string                               | Значение должно быть строкой                       |
| login   | Value should be at most <max limit> symbols        | Значение должно содержать не более <max limit> символов |
| login   | Value should be at least <min limit> symbols       | Значение должно содержать не менее <min limit> символов |
| login   | Login does not exist                               | Логин не существует                                |
