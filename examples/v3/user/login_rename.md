## Переименование пользователей
### Список ошибок
| Атрибут | Ошибка                                             | Описание                                            |
|---------|:---------------------------------------------------|-----------------------------------------------------|
| from    | Value is required                                  | Значение обязательно                               |
| from    | Value must be string                               | Значение должно быть строкой                       |
| from    | Value should be at most <max limit> symbols        | Значение должно содержать не более <max limit> символов |
| from    | Value should be at least <min limit> symbols       | Значение должно содержать не менее <min limit> символов |
| from    | Login not exists                                   | Логин не существует                                |
| to      | Value is required                                  | Значение обязательно                               |
| to      | Value must be string                               | Значение должно быть строкой                       |
| to      | Value should be at most <max limit> symbols        | Значение должно содержать не более <max limit> символов |
| to      | Value should be at least <min limit> symbols       | Значение должно содержать не менее <min limit> символов |
| to      | Bad login format                                   | Неверный формат логина                             |
| to      | Login is already exists                            | Логин уже существует                               |
